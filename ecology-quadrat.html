Quadrat counter

Count plants or animals quadrat by quadrat with big tap buttons, then get density, frequency, importance value and diversity indices (Shannon, Simpson, evenness) without a calculator.

1. Study setup

For example 1 m × 1 m = 1 m², 0.5 m × 0.5 m = 0.25 m².

2. Count

Tap + for each individual counted in the selected quadrat. Species you add appear in every quadrat. Use a name like "Unknown grass 1" for plants you cannot identify yet and rename them later by exporting and editing the CSV.

How each number is worked out

Let ni be the individuals of species i over all quadrats, N the total individuals, S the number of species, Q the number of quadrats and A the quadrat area.

  • Density = ni / (Q × A). Relative density = ni / N × 100.
  • Frequency = quadrats containing the species / Q × 100. Relative frequency = frequency of the species / sum of all frequencies × 100.
  • Importance value here = relative density + relative frequency (maximum 200). It leaves out relative dominance because this tool counts individuals and does not measure cover or basal area.
  • Shannon index H′ = −Σ pi ln pi, with pi = ni / N. Simpson index D = Σ pi²; the diversity form 1 − D is shown, and 1/D.
  • Pielou evenness J = H′ / ln S (shown when S > 1). Margalef richness = (S − 1) / ln N (shown when N > 1).

These indices describe the sample you counted. A handful of small quadrats gives rough values, so compare sites only when you used the same quadrat size and number of quadrats.
