About this page

All results are computed from the standard textbook formulas, using the small-angle approximation for the screen patterns where noted. The brightness of the fringes on the screen is drawn on a gamma scale so that dim fringes stay visible, so compare heights on the graph for true relative intensity. Symbols here follow common international notation (d for slit separation, a for slit width, N for lines per unit length, n for the order or the refractive index). Your textbook may use different letters, for example β for fringe width.
