Acid-Base Titration

Run sodium hydroxide into an acid drop by drop. Watch the pH curve build and the indicator change, and find out why the wrong indicator gives the wrong answer.

Set up the titration

The flask holds 25.0 mL of acid. The shaded band on the graph is the pH range where the indicator changes colour.

Try this

  • Titrate HCl with phenolphthalein, then with methyl orange. Both work. Look at how tall the steep part of the curve is and say why.
  • Switch to CH₃COOH and try methyl orange again. Where does the colour change, and how far is that from the true neutralisation point?
  • For the weak acid, read the pH when exactly half the NaOH has been added. Compare it with pKa = 4.74.
  • Double the NaOH concentration. Predict the new burette reading before you run it.

The chemistry

At neutralisation: Cacid Vacid = Cbase Vbase
pH = −log [H⁺]
Weak acid buffer region: pH = pKa + log ([salt] / [acid])

The curve is found by solving the charge balance [H⁺] + [Na⁺] = [OH⁻] + [A⁻] at 25 °C, with Ka = 1.8 × 10⁻⁵ for ethanoic acid and Kw = 10⁻¹⁴. Indicator colours are drawn as a smooth blend across the stated range; real colour judgement varies from person to person.
