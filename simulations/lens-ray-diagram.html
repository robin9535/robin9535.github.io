Lens Ray Diagram

Drag an object in front of a convex or concave lens. The rays redraw as you move it, and the image is located, measured and described for you.

Set up the lens

You can also drag the object along the axis in the picture. Solid lines are real rays of light. Dashed lines show where rays only appear to come from. Heights are drawn three times larger than distances so the arrows are easy to see.

Try this

  • With the convex lens, start far away and slide the object in. Note what the image does as you pass 2F, then F.
  • Put the object exactly at 2F. Compare the image size and distance with the object's.
  • Move the object inside F. This is how a magnifying glass works. Which side is the image on, and could you catch it on a screen?
  • Switch to the concave lens. Can you find any object position that gives a real image?

The equations

1/u + 1/v = 1/f
m = v / u = image height / object height

Sign rule used here: distances to real objects and real images are positive. A negative v means a virtual image on the same side as the object, and a concave lens has a negative f. If your textbook uses the Cartesian rule the signs differ, but the picture is the same. The lens is treated as thin.
