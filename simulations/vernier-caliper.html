Set up the caliper

Try this

  • In Explore mode, slide the object width slowly. Watch the vernier zero move along the main scale and the coinciding line shift one step each time.
  • Switch to LC 0.05 mm. The vernier has 20 divisions now, so the reading is twice as fine.
  • Set a zero error of +2 divisions. The jaws read a width even when closed, so the observed reading is too big. Subtract it.
  • Try Practice. Read the scales yourself, type the corrected reading, then press Check.

The equations

Least count = 1 main-scale division − 1 vernier division
LC = 1 mm / N,  with N vernier divisions equal to (N − 1) mm
Reading = MSR + (coinciding line × LC)
True reading = observed reading − zero error

A negative zero error (the vernier zero left of the main zero when closed) is subtracted too, so the correction is then added.
