First time? How to get access (about 10 minutes)
  1. Register for Earth Engine at earthengine.google.com/signup and choose non-commercial use (research, education).
  2. In the Google Cloud Console, create or pick a project and register it for Earth Engine. Copy its project ID into the box above.
  3. Enable the Earth Engine API for that project.
  4. Come back here, press Sign in with Google and allow access.

If sign-in fails with "origin not allowed", the site owner must add this site's address as an authorised JavaScript origin on the OAuth client.
